# NYU Cyber Fellows Portfolio

**Hands-on graduate projects from the Master of Science in Cybersecurity**  
New York University – Tandon School of Engineering (NSA Cyber Operations program)

This repository showcases practical work completed during my 2019–2024 Master’s program. Each folder contains real technical deliverables, scripts, reports, and analysis that demonstrate applied skills in penetration testing, digital forensics, network security, and cryptography.

### What You'll Find
- **Penetration-Testing**  
  Full professional penetration test of a fictional organization, including scope, methodology, detailed findings, screenshots, and remediation recommendations. Also includes the original PenTest contract. (This is the strongest project and best reflects real-world reporting skills.)

- **DigitalForensics-2024**  
  Python-based forensic tools I built, including an EXIF metadata parser, browser history analyzer, and network capture parser.

- **Network-Security**  
  Labs and scripts focused on network reconnaissance, traffic analysis, and secure configuration.

- **Applied-Cryptography**  
  Implementations and analysis of cryptographic algorithms and protocols.

### Skills Demonstrated
- Vulnerability discovery and exploitation  
- Professional technical writing and risk reporting  
- Python scripting for security tasks  
- Digital forensics and evidence handling  
- Network defense and analysis  

All projects were completed as part of the NYU Cyber Fellows program and reflect current industry tools and methodologies (Kali Linux, Metasploit, Burp Suite, etc.).

**Repository last updated:** 2024–2025
